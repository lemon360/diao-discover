# 屌软件 Discover 1.4.0

面向 nihendiao.com 的原生 WordPress 软件发现主题。借鉴 Product Hunt 的发现列表与精选布局，采用珊瑚橙、留白和清晰的信息层级。所有功能集成在主题内，没有必须安装的第三方插件，也没有前端构建步骤。

[下载安装包](https://github.com/lemon360/diao-discover/releases/latest) · [更新记录](CHANGELOG.md) · [安全反馈](SECURITY.md) · GPL-2.0-or-later

## 安装

要求：WordPress 6.4+、PHP 8.0+。本次在 WordPress 7.1.4、PHP 8.3.36 的独立测试站验证；数据库使用官方 SQLite 集成组件。生产环境 MySQL/MariaDB 尚未实机验证。

1. 在测试环境备份数据库及现有主题/插件配置，上传本主题 ZIP：**外观 → 主题 → 添加主题 → 上传主题**。
2. 激活「屌软件 Discover」。主题包根结构为 `diao-discover/style.css`，不要上传整个开发工作区。
3. 在 **设置 → 阅读** 选择「你的最新文章」，显示本主题的发现首页。若保留静态首页，主题会尊重原有设置，展示该页面正文；文章列表由所指定的文章页展示。
4. 进入 **外观 → Discover 设置** 配置品牌、首页介绍、精选文章 ID、广告和 SEO。
5. 在 **外观 → 自定义 → 站点标识** 上传 Logo 和站点图标；在 **外观 → 菜单** 分配顶部和页脚菜单。
6. 保留现有永久链接结构。在 **设置 → 固定链接** 保存一次；刷新页面缓存/CDN，检查旧文章、分类、图片、下载链接和评论。

安装包没有演示文章、WordPress 核心、测试账号、数据库或本地配置，不会自动覆盖文章。

## 现站内容如何使用

本主题沿用原生 `post`、`page`、`category`、`post_tag`；无需将数千篇旧文章迁移到新内容类型。旧文章直接显示原有标题、摘要、特色图片、正文和评论，文章 ID 和永久链接不变。

对现站 `pc / mobile / tv / online / tutorial` 和各软件分类提供默认导航，找不到这些 slug 时退回已有分类。自定义菜单优先。

教程/资讯会自动识别 `tutorial / jiao / news` 及常用中文分类名，包含全部子分类，并从应用列表、应用精选、应用分类入口、应用搜索/归档和右侧软件推荐中分离；教程/资讯的原有分类 URL 和正文仍正常访问。在主题设置中可指定「教程/资讯分类 ID」覆盖自动识别。首页精选需填写最多 3 个真实文章 ID；未配置时不显示精选卡片。

旧主题/旧插件独有的 shortcode、下载元数据、登录组件和付费功能不会自动转换。正文中已有的普通 GitHub 项目链接可识别为仓库入口；保留旧插件直到相关旧文章的依赖完成核对。主题不会更改、清理或停用旧插件。

## 侧栏卡片与文章文案

进入 **外观 → Discover 设置 → 侧栏与文案**：

- 顶部介绍卡片：独立开关；可编辑顶部小字、标题、正文和按钮文案，标题/正文支持换行。按钮可选邮件订阅、RSS、自定义链接或隐藏；自定义链接单独填写。
- 底部开源卡片：独立开关；可编辑标题、正文、按钮文字与 URL。留空链接或按钮文案可隐藏按钮。
- 「文章末尾分享引导文字」：修改原来的「好软件，值得分享。」；留空只隐藏文字，分享按钮保留。仅保存纯文本。

关闭两块卡片不会移除教程资讯小工具、广告或软件推荐。旧配置升级时默认保持开启。

## 教程/资讯小工具

进入 **外观 → 小工具 → Discover 右侧边栏**，添加 **Discover · 教程与资讯**。可以放多个实例，分别设置「教程」和「资讯」，自由调整顺序；每个实例可设置标题、多选分类、显示数量（1–10）、最新/评论数排序和是否显示日期。分类自动包含子分类。

未配置侧栏时默认展示最新教程/资讯。添加任意小工具后，使用你配置的小工具；默认回退可在主题设置中关闭。原有广告和软件精选仍独立显示。右侧栏在窄屏按原设计收起，教程/资讯仍能从顶部导航访问。

## 发布软件

新建/编辑文章，在 **Discover · 软件信息与 SEO** 面板填写：

- 软件短名称、一句话介绍；未填时使用文章标题和摘要。
- HTTPS GitHub 仓库、官网和官方下载链接。
- 平台、开源许可证、版本、特色标签。
- 本文章独立 SEO 标题和描述。

特色图片作为列表图标，建议上传正方形的 PNG/WebP；正文中可插入软件大截图。文章详情有软件信息栏、仓库/官网/下载入口、收藏、分享、推荐、目录、代码复制、相关文章和评论。没有字段时自动简化布局。

只填写真实的开源许可证，不要把「免费」作为开源协议。没有许可证不会默认把免费软件标成开源。

## GitHub 数据

保存仓库地址后，在文章信息面板点击 **同步 GitHub 数据**。主题请求固定的 `api.github.com/repos/owner/repo` 接口，保存 Star、Fork、语言和许可证，成功缓存 1 小时，失败冷却 5 分钟并保留旧数据。详情页标注缓存日期。

访问前台不触发 API 请求。没有成功同步时不展示 Star 数字。支持不带 Token 的公开仓库接口；受 GitHub 匿名配额和服务器连通性影响。接口失败会在编辑后台提示，不影响文章展示。

## 推荐、收藏和投稿

- **推荐**：游客直接点击即可推荐，再点可撤销，刷新后恢复状态。首次点击时创建站点签名的第一方 HttpOnly / SameSite=Lax Cookie，保存浏览器访客身份一年；普通浏览只读取状态，不创建该 Cookie。每个访客身份/文章最多 1 条推荐。清理 Cookie、切换浏览器会生成新身份；不是按真实个人去重。已有登录账户的推荐记录保留在 `数据库前缀_dh_votes`，访客记录保存在新增 `数据库前缀_dh_guest_votes` 表；人气排序合并两类票数。升级只增加表，不清空旧推荐。
- **收藏**：保存于当前浏览器的 localStorage；最多展示最近 100 项，不跨设备同步，清理浏览器存储后会消失。无需账号。
- **匿名投稿**：顶部「推荐好软件」打开 `/?dh_submit=1`。无需登录或注册，填写软件名称、文字介绍和 GitHub/官网，提交为**待审核文章**。管理员在 **文章 → 所有文章 → 待审核** 中审阅、补分类/软件信息再发布。访客投稿作者为 0 并标记访客来源，发布时可由编辑指定作者。仅接受文字和链接，服务端拒绝任何图片/文件上传，正文不接受 HTML 图片或富文本。匿名来源按服务端网络地址的不可逆摘要限制每 5 分钟一次，不保存原始地址；同时校验 nonce、蜜罐与并发锁。
- 投稿和推荐均不依赖注册开关。也可在主题设置中填写自己的投稿页面 URL。若使用页面缓存/CDN，请为 `dh_submit` 查询参数和 `admin-post.php` 排除缓存。反向代理需由服务器正确设置 REMOTE_ADDR；主题不信任任意客户端转发头。
- 评论使用 WordPress 原生评论与审核设置，不包含独立账号系统；邮件订阅使用下面的主题模块。

切换主题不删除文章、软件元数据、设置和推荐表；如需跨主题继续使用投稿/推荐功能，应将相应模块迁移到插件。

## 邮件订阅与发信

进入 **外观 → Discover 设置 → 邮件订阅**。内置入口为 `/?dh_newsletter=1`，侧栏介绍卡片和页脚可以进入；订阅页标题、说明、发件人和通知范围均可修改。

- 填写邮箱、同意接收后发送确认邮件；确认链接 24 小时有效，必须打开页面点击按钮后才激活。确认之前不会发送文章通知，确认 token 在数据库中仅保存摘要。邮件扫描器仅打开链接不会订阅或退订。
- 开启新文章通知后，仅首次公开发布的普通文章进入队列，不补发存量文章；编辑已发布文章或撤回重发不重复通知。默认排除教程/资讯及加密文章，可选择包含教程/资讯。已使用过本模块记录首次发布的文章，后来开启通知也不会补发。
- WP-Cron 默认每批最多发送 5 封，可调 1–25。每个收件人单独发送，失败最多尝试 3 次；退订后队列中的未发邮件会取消。这里的“已发送”表示发信服务接受请求，不代表已进入收件箱。
- **外观 → Discover 邮件订阅** 可查看确认/退订状态和队列概况、删除邮箱及关联通知记录、导出已确认邮箱 CSV。仅管理员可访问。主题不自动导入现有用户或评论邮箱。
- WordPress 发信与计划任务必须在服务器上正常运行。低访问量站点建议配置服务器定时调用 WP-Cron；关闭 WP-Cron 时需另设调度。更换主题会暂停主题任务并保留数据。

兼容现有 `wp_mail` 发信插件；不使用发信插件时，可在服务器的 `wp-config.php` 中设置以下常量，放在加载 WordPress 之前。请使用自己发信服务的主机、端口、授权码及已验证发件人：

```php
define('DH_SMTP_HOST', 'smtp.example.com');
define('DH_SMTP_PORT', 587);
define('DH_SMTP_ENCRYPTION', 'tls'); // 支持 tls / ssl / 空字符串
define('DH_SMTP_USER', 'newsletter@example.com');
define('DH_SMTP_PASSWORD', 'YOUR_SMTP_APP_PASSWORD');
```

SMTP 密码不要放到主题、公开仓库或前台统计代码中；同时使用 SMTP 插件与常量时只保留一种配置。正式上线请实际验证确认邮件、通知和退订，并在邮箱服务商配置 SPF / DKIM / DMARC；本地验证使用邮件捕获器，没有验证真实 SMTP 投递。参考：[WordPress 邮件配置](https://developer.wordpress.org/advanced-administration/server/mail/)、[wp_mail 返回值](https://developer.wordpress.org/reference/functions/wp_mail/)、[WP-Cron](https://developer.wordpress.org/plugins/cron/)。

订阅者表包含邮箱、状态、创建/确认时间及确认 token 摘要；不保存原始 IP。限流使用网络来源摘要与短期 transient。请在站点隐私政策中说明用途、保存期限与联系删除方式；可在订阅管理中删除记录。CSV 包含个人邮箱，不应上传公开仓库。

## 统计代码与浏览量

进入 **Discover 设置 → 统计与浏览**，可粘贴完整的百度、Google Analytics、Umami 等统计代码，并选择页面头部或页脚。开关关闭保留代码；默认排除已登录用户，订阅页面始终排除，以免统计服务读取确认链接。只有拥有 `unfiltered_html` 权限的管理员可保存任意脚本；请仅使用可信服务并按站点需要配置访客同意机制。

文章浏览量与第三方统计独立：前台可见停留 1.5 秒后异步提交，页面缓存不会阻止统计；同一浏览器本地和服务端同一网络来源 + UA + 文章 30 分钟去重，忽略常见机器人及有编辑权限的访问。计数是估算阅读次数，不是唯一人数或反作弊系统；共享网络、清理存储等会影响数值。服务端仅保留短期来源摘要，不保存原始 IP/UA。支持总开关及前台数字显示开关，后台文章列表也有浏览量列。

数据表为 `数据库前缀_dh_subscribers`、`数据库前缀_dh_mail_queue`、`数据库前缀_dh_post_stats`；切换主题时保留，恢复主题后可继续使用。浏览量不伪造历史数字。

## SEO

包含原生页面标题、文章 canonical、归档 canonical、description、Open Graph、Twitter Card 和 JSON-LD Article/SoftwareApplication 信息。文章多页阅读与分页使用 WordPress 原生链接。

搜索、收藏、排序、投稿和邮件订阅页面设置 noindex；采用 WordPress 核心 sitemap：`/wp-sitemap.xml`。生产站点应在 **设置 → 阅读** 中检查「建议搜索引擎不索引本站点」是否符合预期；该设置优先于主题。主题不会承诺收录或排名。

检测到 Yoast、Rank Math、AIOSEO 或 SEOPress 时，内置 SEO 自动让位；其余 SEO 插件可手动关闭内置 SEO。社交分享图建议使用可公开访问的 JPG/PNG（例如 1200×630）。

## 广告和分享

广告位：**首页顶部、列表内、侧栏、正文后、全站页脚**。支持图片+链接或可信广告 HTML（HTML 优先）。只有拥有 `unfiltered_html` 权限的管理员可以保存脚本，符合 WordPress 多站点权限规则。图片广告自动标为 `sponsored noopener nofollow`，展示「赞助推广」。未配置/停用的广告不占位；侧栏仅在桌面显示。

点击「分享」打开本站社交分享菜单，直接选择微博、QQ、QQ 空间、X 或 Telegram；不调用系统原生分享、不启动邮件客户端。微信入口复制链接后粘贴到微信。对话框支持 Escape、关闭按钮、背景点击和焦点返回。移动端有完整分类菜单、搜索和收藏入口。

默认浅色为暖灰/米白，深色为低饱和灰绿，正文、次级文字、侧栏、按钮、代码块和弹窗使用统一色彩变量。原版橙色默认值自动按柔和砖红色渲染，其他自定义强调色保留。默认主按钮文字与正文对比度在明暗模式均经检查；自选颜色需自行核对可读性。

## 优化与安全

进入 **外观 → Discover 优化与安全**，该页独立保存，不会覆盖外观/广告设置。

**默认开启的防护：**关闭 XML-RPC（直接返回 HTTP 403）、关闭 Pingback/Trackback、禁止匿名读取 REST 用户列表、禁止匿名批量 REST、登录失败来源限流、隐藏登录账号/密码差异提示、禁用后台主题与插件文件编辑、补充基础响应头。管理员登录与编辑器、主题匿名投稿和游客推荐继续使用必要的接口。

登录默认按同一服务器来源最多 5 次连续失败，在 15 分钟窗口内暂停登录；成功登录清除记录，已有会话不注销。来源只读取 REMOTE_ADDR 并存储摘要；共享网络/代理可能共用额度，服务器应先正确配置真实来源。如已有安全插件提供同类限流，可只保留一套。可从此设置页调整次数、窗口或关闭限流；如意外无法登录，可通过服务器配置/数据库恢复 dh_tools 的 limit_login 为 0，或临时切换主题。

**默认性能清理：**移除 Emoji 兼容资源及生成器/RSD/WLW/短链接/REST 发现标签。其他选项均按需开启：自动嵌入、oEmbed、Feed、访客 Dashicons、前台 jQuery Migrate、后续修订数量、Heartbeat 间隔、智能引号、WordPress 大小写修正、经典编辑器、经典小工具和仪表盘新闻。每项都附有影响说明。

修订数量限制会在后续保存文章时按核心规则保留指定数量；不会执行批量清库。Feed 关闭时主题会隐藏 RSS 入口，不能据此阻止网页采集。关闭 oEmbed 不会全局关闭 REST。应用程序密码默认保留，可按需关闭，以免影响远程发布。

主题不会关闭自动更新，不强制 CSP/HSTS、不修改服务器防火墙规则。已有 wp-config.php 的 DISALLOW_FILE_EDIT 等配置优先。安全功能仅在此主题启用期间运行，不能修补第三方插件漏洞、阻挡所有攻击或替代服务器/WAF、强密码/双重验证、持续更新与备份。

参考：[WordPress 官方加固指南](https://developer.wordpress.org/advanced-administration/security/hardening/)；[XML-RPC 开关范围](https://developer.wordpress.org/reference/hooks/xmlrpc_enabled/)。

**HTML 源码压缩（默认关闭）：**在优化与安全页的性能选项中启用，保守去掉块级标签间空白，保留行内文字分隔、script/style/pre/textarea/code、SVG/Math 与 HTML 注释；遇到嵌套 SVG 会保留原文。后台、REST、Feed 和非 HTML 响应不压缩。主题原始模板已较紧凑，收益可能有限；此项不是服务器 gzip/Brotli。出现插件排版异常时关闭并清缓存。

## 更新与缓存

上传 1.4.0 ZIP 覆盖旧主题后，打开一次后台，主题会自动新增订阅者、邮件队列、浏览量及尚缺的访客推荐表；旧文章、主题设置、投稿和账户推荐保留。清理页面/CDN 缓存，确保载入带 `ver=1.4.0` 的新样式和脚本。`/wp-json/diao/v1/*` 包含动态推荐与浏览量接口，不应由 CDN 缓存；接口返回 no-store。为 `dh_newsletter`、`dh_submit` 参数及 `admin-post.php` 排除页面缓存，确认与退订链接不要缓存或重写。

## 轻量设计与插件替换

主题自有前台仅 1 个 CSS、1 个 JavaScript 文件，无 jQuery、外部字体、图标库和打包框架依赖。GitHub 数据由后台同步，图片使用 WordPress 缩略图和懒加载。

内置功能可替代简单的分享、目录、代码复制、广告位和基础 SEO 插件。缓存、备份、反垃圾和现有内容依赖仍按网站实际需求保留；没有做服务器或 CDN 层的替换。
